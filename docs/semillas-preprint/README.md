# Semillas para preprint / apertura de código

Esta carpeta es distinta de `docs/features/` (que documenta *qué* se implementó, como un
changelog técnico). Acá se registra el **por qué**: la motivación y el razonamiento detrás de
decisiones de diseño de sustrato.ai, mientras están frescas — pensado como insumo directo para:

1. Escribir el próximo preprint académico sobre sustrato.ai.
2. Documentar el proyecto de cara a su eventual publicación en un repositorio de código abierto.

No son requerimientos ni especificaciones técnicas — son notas de por qué se tomó tal decisión de
diseño y no otra, escritas en el momento en que se tomó, no reconstruidas después de memoria.

## Convención

Un archivo por semilla, nombrado `YYYY-MM-DD_slug-descriptivo.md`, en orden cronológico. Cada
archivo debería cubrir:

- **El problema**: qué necesidad real lo disparó (no una necesidad hipotética).
- **La decisión**: qué se eligió hacer, y qué alternativas se descartaron y por qué.
- **La proyección**: por qué esto importa más allá del caso puntual que lo motivó — qué patrón
  general revela, o qué prepara para trabajo futuro.
