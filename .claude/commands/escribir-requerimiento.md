Modo interactivo para definir un requerimiento nuevo.

Pasos:
1. Preguntar al usuario que quiere lograr (funcionalidad, fix, mejora)
2. Hacer preguntas de clarificacion (maximo 3 rondas)
3. Explorar el codigo existente relacionado para entender el contexto
4. Escribir el requerimiento en formato estructurado:

```
## Requerimiento: [titulo]
### Fecha: [hoy]
### Contexto
[Que existe hoy y por que se necesita el cambio]
### Objetivo
[Que debe lograr, criterios de aceptacion]
### Archivos involucrados
[Lista de archivos que se tocaran, basado en la exploracion]
### Plan de implementacion
[Pasos numerados, concretos, sin ambiguedad]
### Riesgos
[Que podria salir mal, que hay que cuidar]
```

Guardar en `docs/cognetica/` si es del modulo cognetica, o en `docs/` si es general.
Confirmar con el usuario antes de guardar.
